## 3. Filter → Sort → Pagination Pipeline

### Filter → Sort (Combo J)
```sql
SELECT id, first_name, lead_status, call_attempts 
FROM leads 
WHERE deleted_at IS NULL AND (call_attempts >= 3 OR interactions_count >= 3) 
ORDER BY call_attempts DESC
```
**Result:** 2 leads returned, sorted by call_attempts DESC (8, then 7)

✅ **PASS** — Sorting applied to filtered dataset, not full table

### Filter → Pagination (Combo K)
```sql
-- Total count (count: 'exact')
SELECT COUNT(*) FROM leads WHERE deleted_at IS NULL AND call_attempts >= 3;
-- Total: 2

-- Page 1 (range 0-9)
SELECT * FROM leads WHERE deleted_at IS NULL AND call_attempts >= 3 
ORDER BY created_at DESC 
LIMIT 10 OFFSET 0;
-- Returns: 2 records
```

✅ **PASS** — Total count is correct (2, not frontend-only filtering). Both records fit on page 1 with standard page size of 10.
